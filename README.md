# OpenWeatherMap API Documentation (One Call API 3.0)

[![Swagger UI](https://img.shields.io/badge/Swagger-UI-brightgreen)](https://goncharovaad.github.io/api-docs/)
[![OpenAPI Specification](https://img.shields.io/badge/OpenAPI-3.1.1-blue)](https://swagger.io/specification/)

This repository contains an interactive API documentation example for the **OpenWeatherMap API (One Call API 3.0)**.

I built this as a portfolio project to demonstrate my skills in technical writing, API documentation, and using **Swagger UI** to create clear and interactive reference materials.

---

## ✨ Features

- **Interactive API Reference**: Browse and try the `current` endpoint with real parameters.
- **No API Key Required for Testing**: The interactive documentation is pre-configured for learning purposes. *(Note: In a real scenario, you'd need your own API key, but this example uses a mock setup for demonstration.)*
- **Built with Modern Tools**:
    - **OpenAPI Specification** (version 3.1.1)
    - **Swagger UI** for a clean, user-friendly interface
    - **GitHub Pages** for easy hosting

## 🧰 Tech Stack

| Tool | Purpose |
|---|---|
| **OpenAPI** | Describing the API structure (parameters, responses, schemas) |
| **Swagger UI** | Generating an interactive documentation page from the OpenAPI file |
| **YAML** | Writing the API specification in a human-readable format |
| **GitHub Pages** | Hosting the static Swagger UI site |

## 📂 Repository Structure

api-docs/
├── workflows #Actions for automation changes and creating Pages
├── index.html # Main Swagger UI page

├── swagger-initializer.js # Swagger UI configuration (points to openapi.yml)
├── .nojekyll # Disables Jekyll for GitHub Pages
